# 0.02 米参考坦克候选

此静态整车由原作者几何按原记录建议的 0.018 米/格重采样到 0.02 米/格。VOX 不自带米制比例，配套 `.vox.meta` 为项目加载器指定 0.02 米。原 0.018 米 VOX 已移除，作者脚本保留；本候选未接入游戏，也未经过引擎画面或美术验收，不能直接替换游戏所需的分部件资产。

从仓库根目录运行 `python tank_model/reference-tank-grouped/build_002.py` 重建，需要 Python 和 NumPy。生成过程按目标格中心采样，保留调色板和场景分组，再回读检查场景与体素颜色索引；生成后的临时渲染缓存不保留。重采样可能损失小细节和颜色，不能等同于在 0.02 米网格上重新作者化。
