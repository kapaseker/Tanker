# 0.02 米网格候选

本目录是原始 0.0125 米静态参考模型的独立重采样候选，不替换游戏资产，也未经引擎或美术验收。每个体素为 0.02 米；配套 `.vox.meta` 供项目的 Bevy 加载器使用。导出后回读检查调色板、场景图、坐标及所有体素颜色索引。

在仓库根目录运行 `python tank_model/leopard2a6_reference/build_002.py` 可重建模型和 `validation.json`。需要 Python 和 NumPy。此流程先生成原作者几何，再以目标格中心采样，并额外映射细天线以保留末端；并非在 0.02 米网格上重新手工作者化。小于目标格的细节与少量颜色可能消失，整体尺寸因量化有最多约一格的偏差。原 0.0125 米 VOX 已移除，其生成脚本和历史预览保留在上一级目录。

该整车模型是静态场景，不能直接替代项目运行时要求的车身、炮管、履带和独立轮资源组合。
