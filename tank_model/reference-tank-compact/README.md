# 参考图坦克体素模型

## 交付文件

- `reference_tank.vox`：高精细主文件，3,833,434 个非空体素，约 15.3 MB。MagicaVoxel VOX 150，包含两块模型和 nTRN / nGRP / nSHP 场景变换，导入时需读取整个场景。
- `reference_tank_single.vox`：单模型兼容文件，505,291 个非空体素，约 2.0 MB。无需场景图支持；每轴缩小至主文件的一半，细节有所损失。若保持相同世界尺寸，体素尺寸应为主文件的两倍。
- `preview_front.png` / `preview_rear.png`：实际体素数据的前后视图软件渲染，并非生成式概念图。
- `reference.png`：用户提供的参考图。
- `build_tank.py`：可重复执行的建模、VOX 导出、结构校验及预览脚本。
- `working_grid.npz`：完整体素工作数据及调色板。
- `validation.json`：导出文件校验统计。

## 坐标和导入

X 正方向是车头及炮口，Y 为横向，Z 向上。主文件工作网格为 480 × 180 × 208；兼容版为 240 × 90 × 104，网格含外围空白。主文件场景坐标与工作网格一致，未设真实米制比例。材质采用 VOX RGBA 调色板，不依赖外部贴图。

这是静态整体模型。两块场景分块按空间切分，不代表车体、炮塔等动画部件。没有绑定、碰撞体或独立炮塔旋转轴；接入动画系统时需进一步拆件。

## 还原范围

依据单张图片重建宽厚车体、双侧履带、七对负重轮、楔形炮塔、长炮管、观察塔、机枪、天线、外挂装甲和格栅。不可见背面按坦克结构补全，不宣称是特定实车的准确工程模型。未将参考图的地面、阴影、景深或背景烘焙进模型。

## 重建及验证

Python 需要已有的 numpy、Pillow 和 matplotlib：

```powershell
python tank_model/reference-tank-compact/build_tank.py
```

脚本会重写本目录的两个模型、工作数据和预览。校验包含 VOX 头、块长度、模型尺寸、坐标边界、颜色索引、重复坐标和主文件体素计数；同时人工检查前后预览。尚未在用户游戏引擎或 MagicaVoxel 应用中实测导入。
