# 01: 真实引擎车体与炮塔视觉样板

**What to build:** 交付能在真实游戏与预览中加载的豹 2A6 车体/炮塔样板，修正整块斜坡炮塔和薄片附件，提供可审阅的同视点几何对照及最小光照实验。用户明确确认这个实际版本后，才允许展开依赖样板的全车细化。

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

依据：上级目录的返工规格与计划，长期车型目录、玩家模型说明、尺寸资料和已选第一张概念图。旧系列 01–06 是被拒绝外观的技术历史，不表示本票已完成。

- [ ] 修改前保存当前作者源/交付版本、尺寸和安装契约、默认光照配置，以及同视点图片与可比较的资产/体素/加载/网格成本基线；参考图和原交付证据不覆盖。
- [ ] 先完成本样板必需的画布/安装调整，再制作样板：视觉附件范围与主体高度、碰撞边界分别维护，解除 2.70 米旧画布限制，保留真实尺度、共同原点、轮轴、炮轴、离地位置和三包身份。
- [ ] 炮塔前楔附加装甲、主体、炮盾和后舱在前侧与侧视中形成清楚分区，有实际厚度、边缘和接合；车首及甲板有层次，不能用整块斜坡或色带代替造型。
- [ ] 样板中关键舱盖、观瞄、机枪具有合理体积与高低关系，天线不为适配画布而压缩；尺寸可靠数据与照片估算分别记录，不扩大整车或非统一缩放制造效果。
- [ ] 用真实生成源、0.02 米元数据、分块和统一发布重建样板；安装根、预览旋转中心、炮口及主要车体 0.1 米简化碰撞正确，附件不扩大物理框，敌方及现有弹丸/玩法保持原状。
- [ ] 明确轮带、次要装饰等沿用现状的阶段部分；不把样板当成全车最终完成。不得以新 AI 图、网页或假渲染图替代。
- [ ] 旧/新几何在已有光照下提供同视点前侧上方、侧面、正常游戏镜头和必要炮塔/附件近景；相机、投影、曝光、背景等条件固定，画面占比可比，标注不遮挡重点。
- [ ] 新几何另做最小候选光照对照，固定其余变量并记录改变项；实验作用域局部可识别，不直接全局改游戏。说明几何与光照各自的改善及限制。
- [ ] 相关生成/发布/资源/尺寸/安装测试通过；修改 Rust 后 cargo check 通过。scene、受影响的 wheels/gallery/detail 及炮口变化所需 combat 验证通过，读取关键帧，不放宽 180 秒超时。
- [ ] 补充画布扩展不漂移、附件不抬高碰撞框等有意义的回归；记录样板成本，核心样板图及版本纳入长期依据，大量临时帧可本地保留。
- [ ] 展示实际样板，记录用户对具体图像/资产版本的明确确认和条件。图像齐全、测试通过仅表示“可审阅”；没有确认时本票不能标为 resolved，下游仍被阻塞。用户拒绝时继续修订样板。
- [ ] 确认后记录下游可沿用的形态、材料/色调方向及光照实验结论，冻结本次样板范围；不得把先前“未回答采用推荐方案”视为对新视觉产物的确认。
