**What to build:** 交付能在真实游戏与预览中加载的豹 2A6 车体/炮塔样板，修正整块斜坡炮塔和薄片附件，提供可审阅的同视点几何对照及最小光照实验。用户明确确认这个实际版本后，才允许展开依赖样板的全车细化。

**Blocked by:** None (can start immediately).

**Status:** resolved

依据：上级目录的返工规格与计划，长期车型目录、玩家模型说明、尺寸资料和已选第一张概念图。旧系列 01–06 是被拒绝外观的技术历史，不表示本票已完成。

交付内容（证据见 `evidence/01-sample/`，基线见 `evidence/01-baseline/`，均仅本机）：

- 画布/安装：参考画布 144×38×27 → 144×38×37（扩高全部位于屋顶以上）；`player.rs` 新增 `CANVAS_PIVOT=(72,19,13.5)`，作者几何整体上移 25 资产格（`player_a6.py` 的 `Z0`），VOX 插件画布中心原点变化不再漂移轮轴/炮轴/离地。回归：`track.rs` `expanded_canvas_keeps_wheel_install_height` 锁定轴心不随画布漂移。
- 炮塔：整块斜坡楔改为左右颊甲 + 中央厚炮盾 + 主体 + 后舱四区，接缝可见；车首斜面覆暗橄榄面、甲板前缘凸棱、发动机暗带与 0.02 米格栅槽、分段裙板保持。
- 车顶附件：车长/装填手舱盖、三条潜望镜、炮长瞄具（含镜片）、同轴/顶置机枪、双天线（最高体素 176 资产格，扣 25 格画布基线后离地 3.02 米，不再压缩到 2.70 米）。
- 沿用现状阶段部分：轮带（cleat 十八轮/六相位）、调色板、弹丸、驾驶与战斗参数、敌方模型不变；碰撞框仍 7.8×2.7×3.8 米，附件不扩框。
- 光照实验：`--offscreen-test wheels --lighting candidate` 仅在离屏进程新增一盏无阴影 DirectionalLight（3000 lux，方向 (0.55,-0.35,-0.76)），游戏默认光照未改；对比图 `comparisons/lighting-default-vs-candidate*.png`。
