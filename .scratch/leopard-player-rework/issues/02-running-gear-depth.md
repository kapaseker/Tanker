# 02: 轮组与履带的厚度及动态层次

**What to build:** 在已获认可的整车样板上，将浅色圆片式轮组和细边框式履带改为有厚度、材料区分和合理包覆的七负重轮行走机构，保留现有完整运动行为。

**Blocked by:** 01 — 真实引擎车体与炮塔视觉样板（必须包含用户对具体样板版本的明确确认）。

**Status:** ready-for-agent

依据：上级目录返工规格、第一张参考图及 01 获认可版本。开工时根据样板结论冻结轮带的具体层次、材料和净空参数；未确认样板不得自行填入假定答案。

- [ ] 每侧仍为七个负重轮和两个端轮，真实比例、轴心和安装方向保持；轮径、轮宽或局部包络若需修正，记录实车资料或估算依据及量化结果。
- [ ] 轮胎、轮毂、中心盖、端轮形成可读的前后深度、边缘与材质关系，深灰橡胶区别于橄榄绿装甲，不能仅给同厚度圆片换色。
- [ ] 履带板有厚度、节距和端部包覆，轮带连接可信；保持轮间透空，避免悬浮横齿、线框边缘或靠碎色假装结构。
- [ ] 与现有裙板检查必要净空，所需局部适配在本票完成；不要留下等待其它票才能加载或行驶的半成品，也不提前修改其它票的无关装饰。
- [ ] 完整旋转包络下轮组与相邻轮、裙板和履带不穿插；左右轮/履带按实际滚动半径和累计里程驱动，闭环相位回绕无跳齿，停车不漂移。
- [ ] 保持 0.02 米作者化、参考格与碰撞规则、共同原点、既有驾驶及战斗参数；新增厚度不悄悄扩大整车标准宽度或物理框。
- [ ] 作者源、交付资产和相关尺寸说明同步，发布检查确定性一致，检查模式不写交付，既有配对失败保护保留；轮轴/净空/清理回归通过，修改 Rust 后 cargo check 通过。
- [ ] wheels 覆盖前进、倒车、左右原地转向及停车，scene/drive 和受影响预览回归通过，实际读取静动态关键帧及轮带近景；保存与旧轮带、获认可样板同条件对照。
- [ ] 正常游戏镜头可读轮带整体层次，近景能辨厚度，不以单纯增加体素数作为完成证据；更新长期模型和成本记录，不把本票完成当成最终美术验收。
