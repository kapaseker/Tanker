# 03: 车体、装甲、附件与炮管整体细化

**What to build:** 沿获认可样板的结构语言，完成其余车首、甲板、裙板、格栅、灯具、车顶附件和炮管细节，使车体与武器在远近视角均有自然、连贯的部件层次。

**Blocked by:** 01 — 真实引擎车体与炮塔视觉样板（必须包含用户对具体样板版本的明确确认）。

**Status:** ready-for-agent

依据：上级目录返工规格、实车尺寸/资料及 01 获认可版本。与 02 没有必需串行关系；共享作者源、裙板及安装契约修改应协调或顺序执行，不表示可无冲突并发。

- [ ] 开工时根据样板认可内容固定剩余细化参数；保持已获认可的炮塔前楔、主体、炮盾和后舱层次，不自行退回简化斜坡或改变整体风格。
- [ ] 车首、甲板、挡泥板、前灯、侧装甲、分段裙板和格栅形成可信连接，板缝及边缘有几何表达，不只在大平面上画暗条。
- [ ] 完善舱盖、观瞄、机枪和天线的独立轮廓、合理体积与安装关系；完整附件包络可加载，不能重新压进旧 2.70 米画布。
- [ ] 炮盾接合、根部、管身、抽烟器和炮口粗细分段在整车镜头可辨，保持 L55 外形与实车比例；不新增制退器、科幻附件或 A7/A8 装备。
- [ ] 橄榄绿装甲、局部暗缝与少量磨损组织形体，与轮带深色材料方向一致；亚体素划痕和螺栓可简化，但主要结构不能以碎色替代。
- [ ] 保持三包身份、真实主体尺度、车体根旋转、炮口和主要碰撞。若局部修正影响契约须在本票完成调用方、资源和测试适配；保留既有弹丸、敌车及玩法。
- [ ] 以当前轮带完整包络检查裙板/附件净空；若 02 已完成，使用其实际交付回归；若未完成，采用已冻结的轮带契约检查，不把未集成部分视为已验收。
- [ ] 确定性重生成与发布检查通过，补齐有意义的几何/装配/炮口回归，修改 Rust 后 cargo check 通过；scene、相关 wheels、combat 及受影响 gallery/detail 通过并读取关键帧。
- [ ] 交付前侧上方、正侧后、正常游戏镜头及重点部件近景，与旧模型和样板同条件对照。游戏和预览使用同一套实际成品，不用专用摄影模型替代。
- [ ] 更新模型说明、尺寸修正/估算和成本记录，标明完成范围及剩余集成验证；不能只凭“部件存在”声称达到参考完成度。
