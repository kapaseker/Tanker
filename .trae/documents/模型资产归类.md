# 模型资产归类：tank/ 下分 player 与 enemy，变体走 default 子目录

## 1. Summary

把 `assets/` 根下的三个坦克相关模型移入 `tank/` 目录，按归属分两层，再按变体分第三层；当前唯一的变体命名 `default`，文件名带父目录前缀便于全局搜索：

```
assets/
├── tank/
│   ├── player/
│   │   └── default/
│   │       └── default.vox                  # 原 assets/tank.vox（玩家坦克）
│   └── enemy/
│       └── default/                         # 敌人当前资源 = 默认变体
│           ├── default.vox                  # 原 assets/enemy_tank.vox（敌人坦克）
│           └── default_explosion.vox        # 原 assets/explosion.vox（击毁爆炸）
├── bullet.vox                # 不动（本次范围外）
├── study.vox                 # 不动（无引用遗留，本次范围外）
├── pisa_*.ktx2               # 不动（环境贴图）
└── terrain/ground/           # 不动（地形）
```

将来新增变体时直接并列目录（如 `tank/enemy/heavy/heavy.vox`），加载路径按变体切换，无需再改结构。

纯移动 + 引用路径更新，不改动任何资源内容与生成逻辑。
