## 1. 目标与尺寸

玩家每侧采用 **5个负重轮＋前后2个端轮**。轮子和履带保存在同一个VOX包，更换履带包时一起更换；包内轮子独立旋转。

为容纳体素轮子旋转后的外缘，将履带适当增高、裙板抬高，保留现有整车外廓。

| 部位 | 确定方案 |
|---|---|
| 车体长／整车宽／整车高 | 保持 **7.5／3.6／2.6米** |
| 负重轮 | 每侧5个，名义直径 **0.8米**、宽 **0.4米** |
| 负重轮轴心 | 距车尾 **1.35、2.55、3.75、4.95、6.15米**；离地 **0.6米** |
| 前后端轮 | 名义直径 **0.5米**、宽 **0.4米** |
| 端轮轴心 | 距车尾 **0.4、7.1米**；离地 **0.65米** |
| 左右轮组横向轴心 | 距车体中线各 **1.4米** |
| 履带主体高度 | 从0.9米增至 **1.2米**，底面保持贴地 |
| 顶齿最高点 | 从1.0米增至 **1.3米** |
| 裙板离地范围 | 从1.1～1.3米抬至 **1.4～1.6米** |
| 履带长度、宽度 | 保持现有7.5米长度和3.6米整车宽度 |

名义轮径指静止体素外包络；生成时限制负重轮所有顶点距轴线不超过 **0.43米**，端轮不超过 **0.28米**，保证连续旋转后仍有净空。

## 2. 模型与资源结构

- 去掉履带内部的实心深灰填充，保留完整闭环、内侧连接结构及轮间实际空隙；不增加悬挂模拟。
- 轮子使用深色轮胎、绿色轮毂和三条不对称分布的浅色辐条，使低速转动也清楚可见；端轮使用可辨认的轮毂标记。
- 裙板保留七块分段结构，只抬高位置；炮塔、车体主体、炮管和镜头保持现状。
- 玩家履带包保留六个履带相位节点，新增十四个独立轮节点：左右各五个负重轮、两个端轮。轮子不再重复烘焙进相位模型。
- 履带继续使用共同画布；轮子使用以轴心为原点的局部模型，通过明确的安装位置挂载。轮位、滚动半径、节点名由生成器和运行时共享定义。
- 敌人继续使用原六相位资源格式，不要求新增轮节点。玩家轮节点缺失或加载失败必须报错，不能静默丢轮。

## 3. 动画与碰撞

- 复用左右履带各自的带符号累计里程，按 **转角＝里程÷滚动半径** 驱动车轮；负重轮半径0.4米、端轮半径0.25米。
- 绕各轮自身轴心连续旋转，正确处理模型坐标映射。前进、倒车、左右差速与原地转向均跟随对应侧履带，停车保持当前角度。
- 履带仍按每0.1米切换一个相位，齿距0.3米；增高后的闭环采用168个轮廓格，保证三相位回绕连续。
- 继续使用一个整体圆角碰撞框，不增加轮子碰撞体。按车身、履带全部相位及车轮旋转包络重新核对边界与中心。
- 预计碰撞尺寸仍为 **长7.5×宽3.6×高2.6米**、中心离地1.3米、圆角0.2米；炮管继续排除。
- 同步更新资源节点数量、加载就绪、显隐、重复挂载和销毁清理契约，避免新增轮实例泄漏。

- `scripts/generate_player.rs`：当前轮组烘焙在六个履带相位中；需要拆出局部轮模型，修改包内各model的SIZE写出方式，不能继续对轮子一律使用整车画布。
