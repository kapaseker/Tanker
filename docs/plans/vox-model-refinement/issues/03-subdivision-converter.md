Status: ready-for-agent
Type: task

## What to build

用一个可复用的标准库转换器，把粗源体素精确细分并写成可由现有插件加载的分块 VOX，先用小样贯穿到真实加载器。

上下文：先读 [规格](../spec.md) 和 [执行方案](../plan.md)，以及阻塞任务的结果与证据。状态仅表示计划可执行，本轮没有开始实施。

## Acceptance criteria

- [ ] 每个输入格恰生成 125 个同色子格，调色板和材质保持；小样涵盖块边界、空白画布、负平移、命名节点与 675/570 格画布，输出坐标和 chunk 长度合法。
- [ ] 保留语义父节点，分块变换还原后彩色体积、米制原点/顶点与粗源一致；奇偶尺寸不产生半格舍入。
- [ ] 转换必须知道源/目标单位并拒绝重复细分；写入新 staging、验证后发布 VOX+meta，失败不损坏输入；避免用数百万 Python 元组常驻内存。

## Verification

- [ ] python -X utf8 -m unittest discover -s scripts -p "test_*.py"，包含新增转换器测试。
- [ ] 以真实 VOX 加载器验证转换小样，不仅自写解析器往返；覆盖 #节点 返回完整分块子树。
- [ ] 如有 Rust 变更则 cargo check；记录转换体素数、字节数、峰值内存和耗时。
