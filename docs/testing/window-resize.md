# 高 DPI 对局加载与窗口尺寸变化

2026-11-03。用户日志在窗口变化时报告深度纹理源宽 2560、复制宽 2562，Bevy 因渲染校验错误退出。回归测试以相同的两像素尺寸变化模拟：图像尺寸改变后，变更事件尚未送达相机系统时，炮镜投影变更使它先刷新，跟随相机仍使用旧尺寸；共享深度纹理因此可能发生不一致。修复在纹理尺寸变化当帧标记相关相机投影，确保它们同帧刷新，同时让小窗 UI 相机采用对局相同的目标缩放。

`resizing_updates_both_gameplay_camera_sizes_in_same_frame` 修复前失败、修复后通过；`cargo check --offline` 和 `cargo test --offline` 通过（149 项单元测试、9 项集成测试）。

`window_resize` 在 AMD Radeon 780M / RADV / Vulkan 上模拟 2× DPI、异步管线编译，从首页进入对局；在加载期间改变尺寸，并在揭幕后连续切换 1282×720、1284×722、1600×900、1280×720，逐次检查主副相机尺寸。退出码 0、报告通过；已查看关键帧。`gunner_sight` 硬件离屏回归退出码 0、报告通过，并已查看副窗关键帧。报告和图片位于本机 `.scratch/offscreen/window-resize-20261103-async-01/`、`.scratch/offscreen/window-resize-gunner-regression-01/`。

此前用户的加载停滞日志没有提供就绪门槛，无法证明其单一根因；本次模拟场景已进入对局并解除黑场。离屏测试没有启用并行渲染线程，也没有创建系统窗口，因此不覆盖真实 X11 窗口管理器的最大化事件和实际显示缩放行为。
