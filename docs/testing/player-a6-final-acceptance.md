## 同机成本对照

01 基线来自本机 `evidence/before-assets.json`、`before-scene/report.txt`、`before-views/report.txt`；最终资产在本机重新解析 VOX，最终运行数据来自 `evidence/06/`。两端均为 1280×720、固定种子 42、RTX 4060 / Vulkan；源码和资产版本不同。加载秒数受文件系统与 GPU 缓存影响，单次结果只作记录。

| 指标 | 01 基线 | 最终交付 |
|---|---:|---:|
| 玩家四个 VOX 合计 | 19,323,436 字节 | 18,882,937 字节（−2.28%） |
| 玩家四个 VOX 体素合计 | 4,827,750 | 4,717,415（−2.29%） |
| scene 启动至渲染就绪 | 12.237 秒 | 10.665 秒 |
| scene 就绪网格实例 / 唯一网格 / 三角形 | 419 / 167 / 118,708 | 423 / 171 / 135,704 |
| wheels 启动至渲染就绪 | 14.808 秒 | 17.568 秒 |

最终其余场景就绪耗时：drive 16.557 秒、combat 18.085 秒、gallery 1.104 秒、detail 1.072 秒。gallery/detail 从首页启动，其就绪时点不等于玩家整车资产加载完成，不用于和 scene 直接比较。现有报告只统计网格实例、唯一网格和三角形；没有可靠的峰值内存或 FPS 测量，文件体积不充当内存指标。当前离屏看门狗为 **180 秒**：04 阶段经批准由 120 秒调整，`detail` 因大量转场曾在并发运行下触及旧预算。本次所有预设在现有预算内通过；没有新增 FPS 或内存门槛。

已知简化：七轮等距分布、局部尺寸按照片比例估算；天线限于 2.70 米画布，未表达资料中端点未明的 3.03 米装备高度；亚体素划痕、螺栓和弹丸尖端作体素化简化。概念图中的细密表面层次没有逐项复刻。交付资产按部件配对保护，四件集合不具事务式发布。以上限制及平台边界不影响本机现有离屏验收结论。
