# 瞄准重做 03：中心十字与炮口会聚

实现日期：2026-11-03。实现与下述自动验证完成；真实键鼠手感和用户视觉认可尚未取得。

对局相机距车体水平 16 米、高 5 米，默认水平观察；高度调整用于让水平视线覆盖车型俯仰范围，同时保留可见的第三人称车体。视角相对车体保存，炮管的视差修正不反馈相机。中心射线与真实弹体共享场景白名单，未命中时使用 2000 米参照。玩家主动位移优先，剩余速度预算用于不能抵消本帧输入的会聚修正；实际俯仰和视角的主动输入按两者共同可执行范围限制。弹丸沿实际炮管发射，不提示命中或对齐状态。

硬件验证：AMD Radeon 780M / Vulkan，固定 1/60 秒；[瞄准报告](../references/aiming-rework-03-2026-11-03/report.txt) 记录近远、26 米不可达、敌人与障碍先后、目标删除、地面、围墙、天空 2000 米、重叠、实射遮挡及限速。真实 UI 布局覆盖 640×720、1280×720、1920×720、0.5 UI 缩放和模拟 1.5 显示缩放，十字中心偏差不超过 2 逻辑像素。显示缩放改变时显式通知图像资产，保证 Bevy 更新相机缓存。

已读取 [地面会聚](../references/aiming-rework-03-2026-11-03/ground.png)、[俯仰限位](../references/aiming-rework-03-2026-11-03/limit.png)、[相机可见远靶但炮口被挡](../references/aiming-rework-03-2026-11-03/blocked.png) 和 [1.5 倍显示缩放](../references/aiming-rework-03-2026-11-03/display-scale.png)。组合驾驶与装填中输入、炮塔微调/反向/释放/失焦、战斗及详情回归的报告保存在本机 `.scratch/offscreen/aiming-rework-03-*`；真实键鼠和其它 GPU 未验证。

已知体验取舍：若近障碍使实际炮管先到俯仰极限，共同输入约束会暂时停止同方向视角移动；玩家可以转车、平移或反向输入使条件改变。该行为避免积压输入，但是否符合预期手感仍需用户判断。
