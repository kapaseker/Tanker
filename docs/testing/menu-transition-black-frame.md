## 复现与结论边界

本次在修改前重新执行：

```text
cargo run --locked -- --offscreen-test menu --output .scratch/offscreen/menu-baseline-20261021-impl
```

退出码为 1，报告中的菜单结构和状态切换断言通过，但 `frame-000120.reject.png` 全黑。已读取该图片确认现象，失败证据保留。

历史证据 `.scratch/offscreen/menu-142617/`、`.scratch/offscreen/menu-143047/` 同样保留。旧文档中“任何全屏 UI 遮罩都会让相机永久全黑”的引擎级判断撤回，降为历史实验假设；这些实验没有充分隔离状态机、平面几何和多相机目标交接，不能据此认定 Bevy 0.20 存在该普遍缺陷。

本次确认的具体问题：

1. 旧 `fade_in` 在 `entity=None` 时创建黑幕；完成时又将其设为 `None`，下一帧重新创建。回归测试实际复现了完成后 alpha 从 0 回到 1。直接进入 InGame 的旧离屏场景也会触发该路径。
2. `Plane3d::default()` 是 XZ 平面，旧实现仅沿相机局部 -Z 平移，没有转向，不能可靠承担全视口遮挡。
3. 揭幕没有等待资源、场景实例和 GPU 管线就绪；菜单、场景相机直接共享最终纹理，切换同时改变相机生命周期与 UI 归属。旧实现逐项修改颜色，还漏掉边框。
4. 地形和敌人的一次性 `Local<bool>` 生成标志无法在返回后重置；原实现没有双向对局生命周期。

这些是已证实的实现缺陷；原来共享目标路径导致全黑的各项 GPU 因素并未被单独归因为引擎缺陷。修复替换了这一交接路径，并用完整双向运行验证最终行为。

## 当前实现契约

- `transition` 模块管理 `Idle → Out → Waiting → In → Idle`。每段渐出、渐入各 0.6 秒，黑场等待不消耗渐变时间；只有明确请求才开始下一次过渡。
- 菜单/跟随相机写内部 `SceneTarget`，独立 `OutputCamera` 把内容纹理合成到窗口或离屏目标。最终不透明材质的 RGB 混合到黑色，所有 UI、文字、背景和游戏内容同步过渡。渲染层31保留给合成四边形，避免相机采样自身。
- 黑场等待字体、标题纹理、地形、玩家/敌人、履带校验、场景实例、网格/图像 GPU 上传与管线编译，连续八帧稳定后揭幕。资产或管线失败会记录具体错误，不当作就绪。
- 加载期间暂停物理时钟，防止实际帧率下玩家在地形加载前落穿；揭幕时恢复。加载物理冻结有独立回归测试；菜单离屏主循环在加载期间也推进正常模拟步长，不靠测试停钟掩盖问题。
- 过渡期忽略确认、Esc、驾驶与开火，揭幕后等待上一页面按键释放。鼠标在同一项内按下并松开才激活，拖出取消。
- Esc 渐出后清理 `SessionEntity` 标记的相机、玩家、敌人、地形、围墙、炮弹、爆炸及其后代，同时清除地形/敌人生成资源、场景句柄和射击冷却。下次 Start Game 重新创建对局。
- 原 scene/drive/combat/wheels 离屏入口直接进入 InGame，过渡保持 Idle，不创建黑幕。

## 首页设计对照

基准仍为 `web/index.html`，未修改设计稿。没有根据死 CSS 增添文案或新页面。

| 项目 | 当前实现与检查 |
| --- | --- |
| 背景 | 暗底、右下沙色余光、右上薄荷余光、透视渐隐网格、扫描线、暗角 |
| 框架与布局 | 仅左上/右下角标；标题菜单与方块作为整体居中；空 HUD 占位与底部版本位置 |
| 标题 | 原稿 MiSans、真实字重及纵向渐变、三层挤出和阴影，从 HTML 两倍分辨率导出并随字号缩放 |
| 菜单 | 两行连续分隔线、编号/文字/箭头、菜单下方键盘提示，删除额外标题和驾驶文案 |
| 悬停/焦点 | 左起渐变展开、左缩进、文字换色、箭头右移、反向收回及各自 CSS 缓动；键盘与悬停使用相同高亮，不额外绘制外框 |
| 键鼠 | 初始无焦点；↑↓循环、Tab/Shift+Tab、Enter、鼠标命中；悬停与键盘焦点分开 |
| Gallery（当时范围） | 完整视觉、可焦点/悬停/点击；Enter 和鼠标激活都无业务动作、无提示。2026-10-23已接通真实画廊，当前行为与验证见[模型画廊验收](model-gallery.md) |
| 方块 | 九枚原始 SVG 位置/比例/面色/透明度、下投影、7秒漂浮、18px局部位移、各自负延迟 |
| 响应式 | ≤900px隐藏方块；≤640px调整字号、菜单行、间距与版本左对齐；另检查480px窄屏 |
| 动态策略 | 按用户决定始终播放完整动画，不读取减少动态偏好、不增加设置界面 |

背景与方块由 `assets/shaders/menu.wesl` 绘制，UI 使用逻辑像素排版；内部纹理使用窗口物理尺寸，图像目标同步窗口 scale factor。实际高 DPI 窗口行为未在本次打开窗口验证。

标题导出脚本为 `scripts/export_menu_title.cjs`。它读取原设计稿和已有字体，校验实际字宽约736.046875px后导出 `assets/menu/title.png`。开发环境需要已有 Playwright；可用 `NODE_PATH` 指定安装目录、`MENU_BROWSER` 指定后台浏览器路径。游戏运行不依赖浏览器。
