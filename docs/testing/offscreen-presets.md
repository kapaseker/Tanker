# 离屏预设选择

需要验证实际场景、GPU、动态效果或画面时，按改动范围选择预设；一次改动可以需要多个预设。纯逻辑优先 `cargo test`。入口、就绪条件、失败处理和窗口限制见 [AGENTS.md](../../AGENTS.md#无窗口测试与画面验证)。

| 改动范围 | 预设 | 主要覆盖 |
| --- | --- | --- |
| 场景、资源、地形、默认相机 | `scene` | 真实场景落地、地形碰撞与相机跟随 |
| 驾驶、车体转向、履带 | `drive` | 真实地形上的直行、转向与履带里程；遇到直行阻塞先读 [已有发现](offscreen-findings.md) |
| 炮塔、炮管、WASD 微调 | `articulation` | 两轴输入、速度和限位、炮口方向、多发弹丸及失焦/锁定 |
| 驾驶、调炮、开火或对局生命周期的组合 | `integrated` | 真实输入下的组合运动、发射、装填中调炮与退出重进 |
| 弹丸、命中、爆炸 | `combat` | 真实开火、敌人命中、爆炸生成与清理 |
| 生命、装填状态显示 | `hud` | HUD 状态簇与真实冷却进度 |
| 高 DPI 加载与窗口尺寸变化 | `window_resize` | 模拟 2× DPI、异步管线、加载中及对局中调整尺寸、主副相机同帧尺寸和揭幕 |
| 炮镜视角、分划与视图切换 | `gunner_sight` | Shift 主副槽互换（长按不连发）、炮镜相机位姿逐帧同步、副窗视口矩形换算、第三人称无准星哨兵、弹丸沿炮口方向、切换前后调炮角不变、分划显隐与读数、Q/E 倍率及副窗十字 |
| 坦克轮组、履带相位 | `wheels` | 轮组运动、方向与停车；敌车追加 `--model enemy` |
| 首页、首页交互与过渡 | `index` | 首页交互、页面过渡及对局清理 |
| 画廊、模型卡片、浏览导航 | `gallery` | 画廊预览、滚动、导航与往返清理 |
| 模型详情、规格、预览交互 | `detail` | 模型详情输入、资源生命周期、失败返回与对局状态隔离 |
| 田园测试场景、自由相机 | `pastoral` | 田园画面、自由相机输入与页面往返 |

从工程根目录运行，将 `<预设>` 替换为表中名称，并为每次运行选择没有同名产物的新目录：

```text
cargo run -- --offscreen-test <预设> --output .scratch/offscreen/<本次目录>
```

例如，炮镜与 HUD 可能分别需要 `gunner_sight` 和 `hud`；共享对局控制改动还应检查 `articulation`、`integrated` 及受影响的详情行为。`wheels` 另有仅用于离屏实验的 `--lighting candidate`，与 `--model enemy` 均为单独可选参数。

检查进程退出码和输出目录内的 `report.txt`，并按改动读取关键帧；有失败或缺少 GPU 能力时按工程规则保留证据并报告，不以截图生成或资源加载成功代替断言通过。预设具体脚本以 `src/validation/scenarios/` 和命令解析 `src/validation/cli.rs` 为准。
