# aiming 03：准星画面边界与对局生命周期验收

日期：2026-11-02。范围：画面外边缘方向箭头、无效投影安全隐藏、完整相机视口投影与多视口/显示缩放逻辑验证、装填与对局生命周期行为；不修改预测规则、相机跟随方式、模型或弹药配置。

## 技术验收

### 离屏（固定 1280×720 GPU 画面）

`cargo run -- --offscreen-test aiming --output <新目录>` 扩展为 14 组布靶：新增抬炮 20°、260m 无命中用例，方向终点投影位于视口上方之外，最终布局断言边缘箭头显示、锚点在 `[min+24, max−24]` 逻辑像素内、尺寸 16px、坐标与角度有限，且十字与命中圆同帧隐藏。原有 13 组预测与真实首碰、接触误差、装填中更新、擦边与遮挡断言全部保留并通过。缺失炮管即时隐藏同时覆盖十字与边缘箭头；对局清理后两者均无残留、预测资源清空。

本机报告：[aiming 离屏报告](report.txt)，退出码 0，`hud` 回归预设退出码 0 且装填中准星照常显示。部署环境备注：验证执行器的命令重试机制曾使三次已成功的运行在产物写完后二次执行并以“目标已存在”退出 1；以各目录 `report.txt`（结果：通过）与关键帧为准，`regression-hud-02` 为一次干净退出码 0 的运行。

### 逻辑测试（其它宽高比与显示缩放，无 GPU 画面）

`reticle` 单元测试使用独立对称透视相机几何：

- 画面内投影在 16:9（1280×720）、较窄（960×720）、超宽（2560×1080）及非 1 显示缩放（物理 1920×1080 @1.5×）下均等于逻辑视口中心，误差远小于 2 逻辑像素；转换只由相机完成一次，不叠加菜单缩放。
- 画面外四边与四角：锚点钳制到距边缘至少 24 逻辑像素且整个 16px 标记留在视口内，指向角与相机 API 独立复算的“视口中心到投影点”方向一致；上方点箭头朝上、右方点朝 +X 的方向语义单独抽查。
- 相机后方、近裁剪面内、NaN、无穷大及无视口信息一律隐藏，不产生锚点或屏幕中心兜底。

### 生命周期

- 装填中预测与准星持续更新且不额外开火：aiming 案例 0 装填期真实 W 输入断言与 `hud` 预设回归保留。
- 玩家、活动炮管或相机缺失：当帧隐藏，不沿用旧位置（炮管缺失用例覆盖）。
- 敌人销毁后不保留旧命中圆（已有断言保留）。
- 退出对局：十字、边缘箭头实体与预测缓存统一清理；重进对局由 `OnEnter(InGame)` 重新生成，仅使用新对局姿态。画廊、详情与田园场景不注册战斗准星或新相机行为。

根目录 `cargo check` 通过；完整 `cargo test --config build.incremental=false` 通过（131 单元 + 9 集成）。

## 限制与后续

固定 1280×720 离屏仅能自然产生上缘箭头（相机随炮塔水平转向，水平指向恒居中，只有俯仰能把投影推出视口）；左、右、下缘及四角由逻辑测试的独立相机几何覆盖，未做对应实际 GPU 画面验收。边缘箭头颜色与尺寸为默认值，随 04 集成验收一并由用户确认。画面内投影贴近视口边缘时十字允许部分越出（中心仍等于投影值）；投影无效时三标记同帧隐藏。
