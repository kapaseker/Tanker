## 实现与验证边界

`player_a6.py` 直接表达 0.02 米几何，Rust 生成器只提供命名画布、材质与独立轮粗源；
删除旧粗主体生成代码和被替代的尾舱示例源。沿用已有 VOX 分块规划、场景结构、meta 和配对发布。
作者化后独立回读分块变换，逐格重建占用/颜色指纹，拒绝漏块、错移、越界、重叠或命名缺失。
故意错移分块的回归确认生成失败且交付资产字节、写入时间不变。
检查模式全流程重建并逐字节比对四个配对，同时检查全部坦克 VOX/meta 的哈希和写入时间未变。
既有转换器的配对发布回滚测试保留；整套四部件仍不是事务。

视觉长宽高由实际资源测量，主要碰撞单独向外取 0.1 米，圆角仍 0.2 米。
三包共享 body 根和单位，炮口为该根前方 7.16 米、地面以上 2.08 米；
旧弹丸的出生中心再前移 0.2 米，旋转后的世界坐标有独立预期值测试。
预览长度守卫读取新视觉契约，尺寸显示与初始取景复用现有几何适配；没有修改 UI 交互。
敌方碰撞高度改用敌方边界，仍为 6.6×2.6×3.4 米；敌方生成器及三个资产字节保持原样。
