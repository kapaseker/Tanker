# 离屏 GPU 排查

离屏报告使用 llvmpipe，或运行环境看不到 `/dev/dri` 时，先分别检查当前环境和宿主机；软件 Vulkan 可运行不代表硬件 GPU 不存在。

1. 在当前环境读取已有离屏 `report.txt` 的 `GPU/后端` 和退出结果，再运行 `ls -l /dev/dri` 与 `vulkaninfo --summary`。缺少 `vulkaninfo` 时记录该限制；不自行安装软件或修改驱动。
2. 如果设备节点不可见、访问受限或只枚举到 CPU 设备，在执行环境允许且取得必要的沙箱外访问授权后，在宿主机只读重跑这两条命令。比较设备节点、设备类型、设备名与驱动；宿主机能枚举硬件但沙箱不能时，报告为沙箱访问限制，而不是断言机器没有 GPU。
3. 需要验证硬件渲染时，在允许访问 GPU 的环境运行对应的工程无窗口离屏命令，使用新的输出目录；检查退出码、报告中的实际设备和关键帧。宿主机枚举到 GPU 本身不能证明游戏场景通过。

宿主机同样没有硬件设备、驱动报错、命令不可用或沙箱外访问被拒绝时，记录实际输出和未验证范围。不要修改设备权限、安装驱动或改用可见窗口绕过限制；焦点和真实输入验证仍须另行取得用户同意。
