- 第 26 页、步骤 39：后部发动机甲板有两个主要圆形风扇格栅。归档[来源页](sources/tamiya-56019-page-26.png)。
- 第 37/39 页、步骤 66/71：炮塔顶部附件及天线布局，不能用中央巨型高塔替代。归档[第 39 页](sources/tamiya-56019-page-39.png)。

| 前灯 | v1 方形大灯，不同图尺寸不同 | 小型圆灯可用阶梯轮廓体素化，保护架与安装点固定 |
| 装甲与牵引件 | 侧裙板缝、后牵引环和尾部挂件数量不同 | 同一面板分区与牵引件布局；遮挡不能改变数量、形状或左右归属 |
