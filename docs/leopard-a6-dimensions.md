# 豹 2A6 基础轮廓尺寸表（工单 02）

冻结日期：2026-10-29，在本票几何实施前记录。长度单位为米，VOX +X 向前、+Z 向上。
这是外观建模契约，不是实车工程测绘。默认普通 A6 的基础轮廓，不增加 A7/A8 配置。

## 来源和口径

- [KNDS A6 页面](https://knds.com/en/products/systems/leopard/leopard-2-a6)：正文实际介绍 A6M，
  炮向前长至 10.97、炮塔顶高 2.64、配置宽 3.77～4.00。用于全长和炮塔顶交叉参考，
  不把 A6M 防雷配置或最大配置宽度拼到普通 A6 上。
- [德国官方装备手册](https://www.bundeswehr.de/resource/blob/5031824/7b51f1e2b8e19099dacc615881c591a4/waffensysteme-und-grossgeraet-data.pdf)：
  A5/A6M 栏宽 3.76、高 3.03。旧 bmvg 链接本次直接获取失败，搜索索引及替代官方手册仍可定位。
  3.03 的装备高度端点不明确，不能用来填高整块炮塔，也不作为天线高度。
- [田宫 A6 官方说明书](https://www.tamiya.com/cms/japan/download/rcmanual/56019.pdf)：
  实车介绍列 Hull length 7.66、Overall width 3.74；这是模型厂商资料而非整车厂图纸。
  车体长度采用 7.66；宽度采用上述装备手册 3.76，保留两来源差异，不声称毫米级精度。
- [田宫 A6 图片与说明](https://www.tamiya.com/english/products/35271/index.html)、KNDS 页面实车照片：
  用于核对长 L55、低甲板和楔形炮塔结构。下表局部尺寸为照片外观比例的粗略建模估算，
  受透视和配置差异影响，不能当作实测；后续 04 可在不破坏总尺寸口径下细化。
