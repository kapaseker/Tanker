# 瞄准辅助意图

确认日期：2026-11-02。状态：设计意图已确认，尚未实现或通过画面验收。

## 目标

让玩家看清当前炮口瞄向哪里，帮助判断这一炮会打向什么位置。摄像机与炮口存在位置和角度差，固定在屏幕中央的准星不能直接代表实际射击指向。

## 已确认的操作与表现

- 保留方向键驾驶、WASD 调炮、空格射击。
- 保持第三人称相机，围绕车体跟随炮塔的水平转向，保留原有跟随距离与高度。
- 相机不跟随炮管上下俯仰；抬高、压低炮管时，由准星位置变化表达射击指向。
- 准星依据实际炮口位置与发射方向计算命中位置，再投影到屏幕，不固定在屏幕中央。
- 调炮、转车和移动时，准星持续对应实际射击路径上的命中位置；预测采用的碰撞规则需要与实际弹丸一致，避免误导玩家。

## 约束与范围

本次不加入鼠标瞄准、自动锁敌、自动调炮或第一人称瞄准镜。

准星的具体形状、无命中目标时的显示方式、指向画面外时的表现留到详细设计。视觉与交互遵循 [UI 设计规范](../../design.md)，最终需要在实际游戏离屏画面中验收。

本文记录设计目标，不代表现有相机或 HUD 已具备上述行为。
