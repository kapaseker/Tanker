# 坦克模型意图

## 目标

以一辆完整坦克为单位制作和使用模型。模型结构应支持坦克各部分的运动，而不是以部件换装为目标划分资源。

## 需要支持的运动

- 车体随坦克移动和转向。
- 炮塔相对于车体水平旋转，炮管随炮塔一起转动。
- 炮管相对于炮塔上下俯仰，以便攻击上下坡的敌人。
- 左右履带表现坦克行进时的运动动画。
- 子弹作为独立对象生成和移动，允许同时存在多发。

## 约束与范围

需要活动的部分保留可独立控制的结构。坦克使用一个还是多个 `.vox` 文件，以实现和制作方便为准；文件数量本身不是目标。

玩家如何操作瞄准，以及不同坦克部件之间的换装，暂不在本意图范围内。

本文记录设计意图，不代表现有模型已经实现或通过验收。
