# ADR-0007：弹药性能随模型配置

- 状态：已采纳
- 日期：2026-11-02

初速和射速归弹药，替代历史炮管性能归属。与弹丸模型同名的 JSONC 文件是唯一性能来源（例如 bullet.vox 对应 bullet.jsonc）；支持 // 和 /* */ 注释，禁止尾逗号。单位固定为米/秒和发/分钟，冷却按 60 / 射速推导。

普通游戏和离屏入口启动时复用资源根路径读取，配置不可用时中文报错并失败退出。配置进程内不变，不提供热更新。剩余冷却属于对局，不持久化。

这是当前游戏规则：同一弹药不因火炮而改变初速或射速。本轮不增加切弹、弹药数量和敌方开火。模型生成器仅发布 vox/meta，保留手工性能配置。
