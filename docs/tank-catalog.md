## 新增车型与维护方式

每款新增车型增加一行，并建立或复用对应模型说明。至少记录：

- **身份与参考型号**：游戏内名称/用途、具体型号及改型；原创车型明确标为原创。仅讨论过的候选车型待选定后再登记为制作目标。
- **资源组合**：车体、炮管、履带及附属弹丸的实际变体。现实车型不替代游戏的部件身份或自动形成锁定套装。
- **还原范围**：外形、尺寸、配色、活动部件，以及保留的游戏化物理和战斗规则。
- **美术依据**：选定概念图、对应型号实车照片；概念图中的尺寸或结构与可靠资料冲突时，注明取舍。
- **尺寸依据**：来源链接、型号、测量端点、量化方式；估算与公开数据分别标注，注明缺失或不确定项。
- **实现和验收**：区分规划中、部分完成、已验收；给出长期验收结论及平台限制。只有相关验收完成后才标记已验收。

详细尺寸、轮位、炮口、生成方式和验证结论维护在各车型文档，本目录提供导航。新增勒克莱尔等车型时沿用这一结构，先确定具体改型再整理资料。

本地工单用于实施过程；最终车型选择、还原取舍和验收结论同步到纳入 Git 的模型文档，关键参考图也随文档保存。临时日志与大量离屏帧可以留在本地证据目录，长期说明应能在这些文件缺失时仍表达设计依据与验证边界。
