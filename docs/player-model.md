# 玩家坦克模型契约

## 车型参考与还原范围

当前玩家采用 **LeoPard2 A6**（来源：astraH Leopard 2A6）完整坦克模型，原始交付位于 [tank_model/leovox_astraH](../tank_model/leovox_astraH/README.md)。本次按[坦克模型意图](intent/tank-model.md)接入，用户于 2026-11-01 确认保留现有造型、配色与尺寸，只改造运动所需结构。资源组织依据 [ADR-0006](adr/0006-whole-tank-motion-assembly.md)。

原模型及作者源完整保留。游戏用资产集中在 `assets/tank/player/leopard2_a6/`，不再用 anvil/lance/cleat 表达新整车身份。旧 anvil/lance/cleat 三包、专用生成器、旧作者化契约与回归夹具已于 2026-11-01 按用户要求删除；历史说明保留。旧尺寸和美术验收见[历史玩家模型](player-model-legacy.md)，不能作为 astraH 集成的验收记录。车型及美术来源仍见[车型目录](tank-catalog.md)、[精细体素半写实基线](art-direction.md)和原模型说明中的冲突取舍。

## 尺寸与运动

安装轴心、轮位和炮口以 `src/tank/model/astra.rs` 为准。

每资产格 0.02 米；车体长 7.66 米、标准宽 3.76 米，炮向前时全长 10.98 米。炮轴离地 2.08 米、炮塔主体屋顶 2.64 米，双天线顶高 4.32 米。观瞄与天线高度为原模型依据设计图的造型估算，不是实车测量。VOX +X 向车首、+Y 向车体左侧、+Z 向上；加载映射为 Bevy `(-X, Z, Y)`。

- 车体随实际驾驶移动和转向。
- 炮塔与舱盖、观瞄、机枪、天线、烟幕筒等附件共同水平旋转。
- 炮管、防盾及耳轴护罩按原 `L55_gun` 分组围绕炮轴俯仰。
- 十八个轮子分别围绕自身轴线旋转，左右履带按各侧行驶里程驱动；停车保持状态。
- 弹丸从实际炮口世界姿态独立生成，之后不随坦克或炮塔转动，允许多发并存。
- 实际弹体扫掠按距离命中敌车、混凝土、地面或围墙中最近的物体；环境命中仅清理弹丸，不破坏环境。旧准星预测采用相同的挡弹范围。

简化车体碰撞框为 7.68×2.68×3.76 米，根节点落地高 1.34 米；附件不扩大碰撞框。车根在原作者坐标的 (192,0,67) 资产格，炮塔轴心为 (192,0,80)，炮轴为 (278,0,104)，炮口端面为 (549,0,104)。三相位按约 0.14 米板距循环，每相位约 0.0467 米；相位 0 保留原静态履带外观。

默认角度为朝前、水平。W/S 抬高、压低炮管，A/D 左右旋转炮塔；按住连续运动、松开停止、反向键抵消，两轴可与方向键驾驶同时操作。炮塔保持相对车体角度，随车体转向；不增加世界方向稳定、鼠标瞄准、瞄准镜或部件换装，相机仍跟随车尾。驾驶与射击操作沿用方向键和空格，前进 16 米/秒、倒车 8 米/秒，弹药参数仍从独立配置读取。

运动参数来自 `assets/tank/player/leopard2_a6/tank.jsonc` 的 `articulation`，启动读取并校验，修改后重启生效。公开俯仰范围 −9°～+20°，水平全周；当前控制速度水平 30°/秒、俯仰 9°/秒是供应商大口径系列参考下的临时游戏采用值，**不是已核实的 A6 专属实车最大速度**。来源、驱动改型差异及未还原的车尾防碰撞联锁见[参数核查](references/leopard-2a6-articulation.md)。

豹 2A6 模型详情支持同一组 WASD，鼠标拖拽整车与滚轮缩放保持可用；进入详情时复位，退出即销毁预览角度，不带入对局。尺寸轴与数字保持默认静态姿态测量，不随调炮跳动。敌车、弹丸详情及画廊卡片不响应 WASD。

## 转换与回归入口

原始作者源见原模型目录；运行时转换器只重组既有体素，不重新作者化整车。现用 APFSDS 弹丸已迁至 `assets/tank/ammunition/apfsds/`，独立入口为 `python3 scripts/generate_bullet.py [--check]`；参考 DM53/DM63 系列飞行体，不声称为某个具体弹种的精确复刻。整车转换仍使用 `python3 scripts/prepare_astra.py [--check]`。转换命令和最终验证结果见[接入验收](testing/astra-player-integration.md)。

弹药初速与射速的权威来源是 `assets/tank/ammunition/apfsds/bullet.jsonc`；冷却按 `60 / rate_of_fire` 推导，剩余冷却只存在于对局状态。配置缺失或非法时阻止启动，无数值兜底。

玩家碰撞体尺寸与圆角半径由 `assets/tank/player/leopard2_a6/tank.jsonc` 配置；弹丸主体扫掠盒由 `bullet.jsonc` 配置。

2026-11-02 参数展示补充：`articulation.traverse_range_deg` 显式记录 360°全周连续范围；俯仰范围和两轴速度沿用同一配置。豹 2A6 详情展示驾驶两项、水平范围、俯仰范围、水平速度及俯仰速度共六项，按两列排列；速度标签不附加状态字样，水平范围显示“全圈”，角度符号与数值同文本排版；来源可信度仍以参数核查文档为准。
