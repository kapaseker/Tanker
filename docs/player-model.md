# 玩家坦克模型契约

默认玩家为原创现代主战坦克体素造型：橄榄绿倾斜首上、低矮棱角炮塔、侧裙板和深灰履带。保持现有驾驶速度、整车朝向开炮，不支持独立瞄准或游戏内换装。

## 尺寸和坐标

权威格坐标及非炮管碰撞边界在 `src/player_model.rs`，生成器和运行时共同读取；每格 0.1 米。三包统一 SIZE 为 135×36×26，VOX +X 为车头、Y 为宽度、Z 为高度。画布中心 X=67.5 正好为车体中心；车尾方向留空 30 格，加载后不需要位置补偿。

- 车体范围 X=[30,105)，长 7.5 米，宽含履带 3.6 米，地面至炮塔顶 2.6 米。
- 炮塔正面 X=90，炮管 X=[90,135)，外露长 4.5 米；炮口相对车体中心前方 6.75 米，轴线离地 2 米。
- 含炮管视觉全长为 10.5 米（车尾至炮口），不能作为碰撞框长度。
- 车身、履带、炮塔共用一个 7.5×2.6×3.6 米圆角碰撞框（Bevy 长×高×宽）；炮管没有碰撞体。框内装甲空隙仍按命中处理。
- 跟随相机后退 16 米、抬高 9 米，保持既有跟随方式，抬头角度调整为 8°，避免车尾被画面下沿裁切。

## 三包与替换规则

| 资源路径（相对 assets） | 节点 | 内容 |
|---|---|---|
| tank/player/default/body.vox | body | 车身、炮塔、炮盾、裙板、舱盖、格栅 |
| tank/player/default/barrel.vox | barrel | 炮管根部、管身、抽烟器、炮口 |
| tank/tracks/player/lugged/default.vox | track_l_0..2 / track_r_0..2 | 左右履带各三个滚动相位及固定轮组 |

所有包使用同一画布、格坐标和调色板，以零偏移挂在玩家根实体下。替换资源必须保持该契约；需要改变炮管长度或轴线时，先修改共享尺寸定义、生成器和相关测试，不通过运行时缩放掩盖不兼容。履带齿距三格、每行驶一格推进一相位，闭环 162 格；轮组不随相位移动。

## 生成与验证

```powershell
rustc --edition 2024 -O scripts/generate_player.rs -o target/generate_player.exe
./target/generate_player.exe
rustc --edition 2024 --test scripts/generate_player.rs -o target/test_generate_player.exe
./target/test_generate_player.exe
python -m unittest discover -s scripts -p test_player.py
python -m unittest discover -s scripts -p test_tracks.py
cargo check
cargo test
```

生成器不读取旧玩家或敌人资源，相同输入输出相同字节。生成器测试对比交付文件；资源测试检查尺寸、三包不重叠和连接面，Rust 集成测试检查真实加载后的组合尺寸、炮口和清理。离屏仍运行 scene、drive、combat 并读取关键帧。

## 旧敌人兼容限制

本轮不修改敌人。现敌人仅高 1.4 米，新炮口离地 2 米，平地水平射击会从其上方掠过。逻辑测试显式覆盖掠过与抬高目标命中。离屏 combat 把原尺寸靶车放在 1.3 米高的实体台座上，以验证真实发射、命中和爆炸清理；这不代表已解决普通平地战斗兼容问题。后续敌人尺寸调整需重新验证此场景。

| 部件 | 本轮尺寸与位置 |
|---|---|

碰撞不是按画布推算：生成器对车身及全部履带相位的并集测量，VOX最小边界[30,0,0]、最大边界[105,36,26]，与共同画布中心重合，无需平移补偿。运行时由这组边界生成7.5×2.6×3.6米圆角框，圆角0.2米；测试核对0°、45°、90°真实碰撞体AABB，炮管不扩大框。圆角会削去方框角部，框内装甲空隙仍参与碰撞。
